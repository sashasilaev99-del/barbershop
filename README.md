# Барбершоп «Бригада» — лендинг для портфолио

Мужской барбершоп: стрижки, оформление бороды, королевское бритьё и онлайн-запись.
Одностраничный лендинг с адаптивной вёрсткой, валидацией формы и мобильным меню.

## Что реализовано

- **HTML5** — семантическая вёрстка: `header`, `section`, `form`, `figure`, валидная структура.
- **CSS3** — переменные, Flexbox, CSS Grid, медиазапросы, плавный скролл, переходы и hover-эффекты.
- **JavaScript** — мобильное меню (burger + Escape + сброс фокуса), подсветка активного пункта меню при скролле, маска телефона `+7 (___) ___-__-__`, валидация формы, имитация отправки заявки.
- **Адаптивность** — десктоп / планшет / смартфон (от 360 px).
- **Доступность** — skip-ссылка, aria-атрибуты, фокус-стили, подписи к полям.

## Как запустить локально

1. Склонируйте репозиторий или скачайте ZIP:

   ```bash
   git clone https://github.com/ваш-логин/barbershop.git
   cd barbershop
   ```

2. Откройте `index.html` в браузере — сайт готов к работе. Сборка не требуется.

## Проверка на устройствах

Откройте в браузере DevTools → Device Toolbar (Ctrl+Shift+M) и проверьте на следующих разрешениях:

- 375 × 667 — iPhone SE (мобильная версия, гамбургер-меню)
- 768 × 1024 — iPad (планшетная сетка)
- 1920 × 1080 — десктоп

Также рекомендую открыть сайт на реальном телефоне: поведение гамбургер-меню, поля формы и маска телефона.
